# ADR 001：按任务类型匹配，拒绝自动归因

状态：接受。日期：2026-09-30。

问题：AI 常用于简单任务，直接比较全部 AI/非 AI 平均耗时可能出现选择偏差。

决策：同时提供原始耗时均值与同类型比较。两组各至少 5 个已完成且有实际耗时的任务才显示时间差；总体使用合格类型的 AI 任务数作权重。缺失分母返回 null，界面显示“—”。不生成“效率提升已证明”的文案。

替代方案：对全体任务计算一个百分比，容易混淆任务组成差异；当前不采用。随机对照实验需要额外协议，不在 MVP 范围。

后果：小数据集经常没有节约率，这是合理限制。n≥5 仅为展示门槛，不是统计显著性，也不构成置信区间。
