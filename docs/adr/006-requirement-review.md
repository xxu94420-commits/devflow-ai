# ADR 006：需求评估以原文证据和人工决策为中心

状态：已采纳；已完成Groq集成验收，模型质量仍需后续人工评测。日期：2026-10-02。

采用现有模块化单体和SQLite，新增需求修订与评估记录。评估固定输入为用户选择的需求标题、描述和验收条件；保存版本快照、输入摘要哈希、Prompt版本、模型标识与用量。模型只返回待澄清问题和原文引用，不输出未经标定的质量分数，不调用工具或直接修改需求。

兼容Chat Completions JSON输出，服务端再严格校验结构、数量、长度和引用来源。无密钥、超时、限流、拒答、截断或格式错误都作为明确失败，不回退成伪装的AI结果。模型地址由服务端配置，界面显示接收方，用户明确确认发送。

需求编辑采用版本比较，过期评估可查看但不能用于修改新版需求。建议的采纳/驳回与需求正文修改分开：采纳表示认可待澄清问题，不表示问题已修复。修改后的需求需重新评估。历史记录不覆盖原快照。

公开模式保留固定synthetic/demo示例，明确标注人工编写、未调用模型。另设默认关闭的无状态云端试用端点；启用后也不允许修改项目数据，不保存访客输入和结果。单进程串行、调用间隔和每日尝试次数只提供应用保护，重启会重置，不替代供应商免费套餐限额。真实模型评测与离线契约测试分开记录，真实调用在用户配置服务后验证。当前单用户模式不宣称团队审批、评估客观性或生产级隐私防护。
